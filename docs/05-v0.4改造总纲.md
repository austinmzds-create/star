# v0.4 改造总纲:面向真实业务的角色便利性重构

> 定位:真实业务系统(非 demo),三角色协同。衡量标准 = **商务/管理员/达人三种人是否都用着方便**。
> 参考:大狗文化商家工作台 —— 简洁、以「产品/视频/投流」为中心、抽屉承载详情、随处复制、卡片+状态分组。
> 原则:**不降级业务**——权限、数据隔离、留痕、物流、投流、快照全链路做真、做全。

---

## 一、设计哲学(三条,贯穿所有页面)
1. **角色便利优先**:每个页面先问"谁在用、为完成什么"。商务是日常高频主力,管理员统管+配置,达人自助查看。
2. **三视角贯通**:同一份数据可从「达人视角」「产品视角」「任务视角」进入,互相跳转,不孤立。例:在达人详情能看到他的寄样/视频/投流;在产品详情能看到该品的授权达人和动态。
3. **简洁高级(不像 OA)**:抽屉(Drawer)承载详情与编辑、卡片+状态分组、分段控件代替下拉、**ID/UID/合作码随处一键复制**、柔和紫主色、清晰空状态与引导文案。

---

## 二、信息架构重构(从"8 个功能菜单"→"角色友好的少而清")
现状菜单偏散(达人库/寄样/催拍/视频投流/产品/卡审/看板/配置 = 8 项,像 OA)。重构为:

| 菜单 | 角色 | 承载 |
|---|---|---|
| **工作台**(新) | 商务/管理员 | 今日待办聚合(待审视频·待发货·待催拍·待处理投流)+ 数据速览 + 快捷入口 |
| **达人** | 商务/管理员 | 达人库列表 + 达人详情(档案/寄样/视频/投流/合作史 一站式) |
| **产品** | 商务/管理员 | 产品列表 + 产品抽屉详情(素材 Tab/授权达人/商品信息编辑/该品达人动态) |
| **寄样** | 商务/管理员 | 待审批/待发货/在途/已签收/已拒绝(卡片+状态分组);历史抽屉(搜索+日期) |
| **视频审核** | 商务/管理员 | 仿抖音 feed 逐条审 + 时间点评论;或列表模式切换 |
| **投流** | 商务/管理员 | 状态机卡片(展开复制到千川)+ 历史抽屉 |
| **知识库** | 商务/管理员 | 卡审记录 + 达人端"拍摄前必读"源 |
| **管理**(折叠,管理员) | 管理员 | 商务管理 + 等级/催拍/拒绝理由配置 + 总览看板 |
| 达人端 H5 | 达人 | 独立极简自助(见 §四.6) |

> 「催拍」不再单列菜单,收进工作台待办 + 达人详情;减少菜单噪音。
> 「视频/投流」拆开(它们是不同工作流,合并反而绕),但在产品详情/达人详情里也能就地看到。

## 四、逐模块改造(整合原 P2–P5 + 竞品范式)

### 4.1 工作台(新增,商务/管理员首页)
- **今日待办**:待审视频 N、待发货 N、逾期催拍 N、待处理投流 N —— 卡片点进对应队列。
- **数据速览**:我的达人数、本周新增、本周产出 GMV(管理员看全员)。
- 商务登录第一眼就知道"今天要干什么",替代现在一进来就是达人列表。

### 4.2 达人(原 P2 达人库 + 详情聚合)
- **录入双模式**(#1):Tab 切换「粘贴识别」/「手动填写」;手动模式空白表单逐项填,支持逐项粘。
- **列表补全**(#2):头像 + 昵称 + 抖音号 + 粉丝 + GMV + 等级 + 佣金 + 标签 + 归属商务 + 轮次 + 状态;空值占位;支持按等级/佣金/商务/标签筛选 + 分页。
- **详情 = 一站式**(#5 + 三视角):
  - 左:档案(可编辑定级/佣金/投流/标签/转移)+ 原始资料
  - 中/右:**寄样记录面板**(寄了几次/时间/品/物流到哪/是否签收)、**视频记录**、**投流记录**、**合作轮次快照**、**变更留痕**
  - ID/UID/合作码随处复制(商务粘到千川/百应)
- **时间全局格式化**(#4)落地。

### 4.3 产品(原 P3 产品中心 + 竞品「商品信息」抽屉)
- **列表补全**(#6):产品图 + 名称 + 店铺 + 价格 + 默认佣金 + 上下架 + 素材数 + 授权达人数 + 创建时间。
- **点击 → 抽屉详情**(#7 + 竞品范式):
  - 顶:商品卡 + 商品链接(复制)+ 上下架
  - **Tab 素材**:AI视频 / 爆款参考 / 达人成片 / 图片 / 质检报告 / 文案 —— 切换查看 + **就地添加**(上传/填链接/写文案),不下拉。
  - **商品信息编辑**:寄样备注 / 带货备注 / 一键审核类型(分段:不需审核·必须审核·18:30自动通过)/ 是否允许带货(分段)/ 默认佣金 / 保存。
  - **授权达人**(#8):达人模糊搜索(回填 id+姓名)+ 已授权列表(可移除);管理员/商务可操作。
  - **该品达人动态**:这个品下的寄样/视频/投流概览(产品视角)。
- 达人端:同款 Tab 只读查看被授权产品的素材(见 §四.6)。

### 4.4 寄样(卡片式 + 竞品历史抽屉)
- 列表改**卡片 + 状态分组**(待审批/待发货/在途/已签收/已拒绝),每卡可展开看达人信息 + 复制。
- 发货:选快递公司 + 单号(已做);列表「刷新物流」实时轨迹(已做)。
- **历史右抽屉**:搜索(抖音名/号/手机)+ 日期区间 + 状态 Tab + 空状态。
- 签收自动进催拍(已做),催拍在工作台待办呈现。

### 4.5 视频审核 & 投流(竞品核心范式)
- **视频审核**:仿抖音 feed 逐条(商品信息左抽屉 + 视频 + 右侧 ✓/✗ + 时间点评论);保留列表模式切换。
- **投流**:状态机卡片(待发起→待确认→已授权→已投流/失败/完成)+ **展开逐字段复制**(抖音号/UID/合作码/链接)+「一键复制」全部(粘到千川)+ 历史抽屉。
- 投流方式(商家投/自投)分段标记。

### 4.6 卡审知识库(原 P4)
- 新增表单增强(#9):违规类型(预设:极限词/夸大功效/未成年口播/功效词无报告… + 自定义)、文案、**视频链接 / 上传原视频**、**多张截图**、**关联达人(模糊搜索,选填)**、发生时间。
- 近 7/15/30 天筛选 + 加星置顶(已做)。
- 达人端「拍摄前必读」只读汇总。

### 4.7 达人端 H5(原 P5,极简自助 + 数据隔离)
- 手机验证码进入(已统一)。
- 首页:我的资料(可完善)、被授权的产品(卡片)、拍摄前必读入口、我的合作/寄样进度(只看自己)。
- 产品素材:同款 Tab 只读 + 下载留痕。
- **数据隔离红线**:后端逐接口只返回本人 + 被授权数据;他人手机/地址/真名一律不可见;前端守卫 + 后端强校验双保险。
