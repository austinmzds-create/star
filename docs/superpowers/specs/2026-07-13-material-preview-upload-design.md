# 素材直显与上传即入库设计

## 目标

解决产品编辑时追加商品图立即显示碎图的问题，并把素材管理改为“上传即完成、内容直接展示”：

- 已有商品图后追加新图，上传、保存和刷新三个阶段均正常预览。
- 文件素材上传成功后自动创建素材记录，不再要求用户再次点击“添加”。
- 管理员产品中心和达人资料中心都直接展示素材内容，不再只显示标题链接。
- 保持现有达人产品授权、文件签名 URL 和下载权限边界不变。

## 商品图预览修复

`MultiUpload` 在编辑已有产品时同时维护两类预览地址：后端返回的历史签名 URL，以及本次上传接口返回的新签名 URL。父组件更新图片 key 数组时，历史映射可能暂时包含 `{新key: undefined}`。

组件合并 `initialPreviews` 时只接收非空 URL，不允许空值覆盖本次上传得到的有效签名 URL。无签名的 `/api/files/{key}` 不能作为正常预览地址，因为本地文件服务按安全设计会返回 403。

## 上传即入库

管理员在产品素材页上传文件时执行一个连续事务式交互：

1. 上传文件到 `POST /api/upload`，取得 `key` 和带签名的 `url`。
2. 立即调用 `POST /api/products/{product_id}/materials` 创建素材记录。
3. 标题优先使用用户已填写的标题，未填写时使用原始文件名。
4. 创建成功后刷新产品详情，新素材立即出现在当前分类并直接预览。
5. 上传按钮在整个流程中显示 loading，阻止重复提交。

AI 视频、达人成片、图片和质检报告均采用该流程。爆款参考同时支持两种入口：上传视频时自动入库并播放；填写抖音外链时仍点击“添加”，因为外链不是文件上传事件。文案仍在填写正文后点击“添加”。

质检报告上传时会携带当前已填写的报告 ID；未填写不阻塞上传，之后可通过素材编辑补充。

若文件上传失败，显示上传错误且不创建素材。若文件已上传但素材记录创建失败，显示“文件已上传，但素材创建失败，请重试”，不虚报成功；当前版本不新增文件删除 API，孤立文件沿用现有存储清理策略。

## 统一素材预览组件

新增共享的 `MaterialPreview.vue`，管理员端和达人端使用同一套类型判断与内容渲染：

- `video_ai`、`video_output`：有文件 URL 时使用带 controls 的内嵌视频播放器。
- `video_hot`：有上传文件 URL 时内嵌播放；只有 `source_link` 时显示外链卡片和“打开原链接”。
- `image`：直接显示缩略图，支持点击放大。
- `pdf`：使用内嵌 PDF 区域直接预览，同时保留“新窗口打开”作为浏览器不支持内嵌时的后备。
- `copy`：直接显示完整正文并保留复制按钮。
- 未识别类型：显示文件标题和“打开文件”，避免完全不可用。

管理员端在预览卡片旁保留编辑和删除操作。达人端保留报告 ID 复制、文案复制以及符合 `downloadable` 权限的下载操作。

桌面管理员端使用适合抽屉宽度的横向素材卡片；达人 H5 使用单列自适应卡片。视频、图片和 PDF 的 URL 都来自现有后端签名 URL，不放宽 `/api/files` 的鉴权要求。

## 数据与权限

不修改数据库模型和现有素材 API schema。管理员上传自动入库只是把当前的“上传”和“添加”两次手动操作串联为一次交互。

达人端仍只能通过 `GET /api/h5/products/{product_id}/materials` 获取已授权产品素材；未授权产品保持 403。管理员和商务的现有产品权限不变。

## 测试与验收

自动化测试覆盖：

1. `MultiUpload` 已有历史图时追加新图，空历史映射不能覆盖新签名 URL。
2. 文件上传成功后自动调用素材创建 API，请求包含类型、key、标题和报告 ID。
3. 素材创建成功后刷新详情并立即显示预览；不需要点击“添加”。
4. 上传失败与素材创建失败分别显示准确错误，不显示成功状态。
5. 共享预览组件正确渲染视频、图片、PDF、文案和外链爆款。
6. 管理员产品中心和达人资料中心均使用共享预览组件。

浏览器验收覆盖：

- 在已有商品图后追加第二张图片，确认立即预览、保存后预览、刷新后预览均正常，网络请求均使用带签名 URL。
- 上传 AI 视频后无需点击“添加”即出现播放器，播放控件可用。
- 上传图片和 PDF 后分别出现图片预览和 PDF 内嵌预览。
- 达人账号进入已授权产品资料中心，看到与管理员一致的直接预览内容。
- 控制台无新增错误，素材请求无 403。

## 非目标

- 不实现抖音外链自动下载、转存或封面抓取。
- 不新增视频转码、图片压缩或 PDF 首页生成服务。
- 不放开无签名文件访问。
- 不修改素材下载计费、下载留痕或产品授权规则。
