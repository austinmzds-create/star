# 共创方案:达人管理平台(v0.3 · 已冻结)

> v0.2:吸收需求方 2026-07-10 答复——移除加权评分卡,改为**商务人工定级 + 动态配置权益**;新增**组织架构与管理员总览**;产品中心扩充;P0 扩容。
> v0.3:§10 五个待拍板项全部有答案,**方案冻结,进入 P0 开发**。
> 产品基调:**清晰、简约、方便使用的小平台**。

## 1. 一句话定位

一套自用的「达人全生命周期管理」小平台:**达人录入建档 → 人工定级(定佣金/寄样策略)→ 商务分工维护 → 寄样物流自动跟踪 → 产品素材自助获取 → 视频/投流协作 → 管理员总览产出**,替代微信 + Excel。

## 2. 角色与组织(A3)

```
管理员 ──┬── 总览看板:按商务看(维护达人数/新增达人数/视频产出/GMV产出)
         │              按产品看(寄样数/视频数/投流数/产出)
         │              按时间筛选(近7/30天/自定义)
         ├── 配置中心:等级权益、佣金档、催拍天数、拒绝理由库、卡审知识库
         └── 产品与素材管理、商务账号管理、达人转移分配

商务 ────┬── 我的达人:只看/维护分配给自己的达人
         ├── 开发新达人:粘贴录入,自动归到自己名下
         └── 日常操作:定级、寄样审批、催拍、视频对接、投流登记

达人(外部,H5 短链)── 手机号+阿里云短信验证码进入
         ├── 自助提交资料(粘贴即识别)
         ├── 查看被开放产品的素材(视频/图片/PDF/文案),可下载
         └── 拍摄必读(卡审知识库达人视图)
```

- 达人**归属商务**(`owner_bd`),管理员可转移;换商务留痕。
- 达人可**打标签**(自定义标签 + 系统标签如"二次合作""爆款出品")。
- 新达人来源标记:商务自开发 / 朋友圈短链自来 / 老达人二次申请(按抖音号/UID/手机号撞库识别)。

## 3. 达人定级(说人话版)

之前说的"评估模型"就是一句话:**给达人分个等级,等级决定给他什么待遇**。v0.2 不做任何自动打分,就是:

1. 商务点开达人档案,看得到参考信息:粉丝数、近30天GMV(先人工填,蝉妈妈接入后自动 ❓待评估费用)、内容品类、能否口播、历史合作记录(系统自动累计:合作第几次、出过几条视频、卡审几次、爆过几条)。
2. 商务凭判断手动选等级 **L1 / L2 / L3**(可随时调,调级留痕:谁、何时、为什么)。
3. 等级自动带出默认待遇(见 §4),商务可在单个达人上覆盖。

> 以后想上自动打分/自动建议,再基于积累的数据谈——现在不做。

## 4. 等级 → 权益:动态配置 + 快照语义(答复#3)

**配置表**(管理员可随时改):

| 等级 | 默认佣金档 | 默认寄样策略 | 视频审核 |
|---|---|---|---|
| L1 | 5% | 单品 | 必审 |
| L2 | 6% | 可2品 | 必审 |
| L3 | 7% | 全品类/主动派品 | 可免审 |

**快照语义(关键设计,按你的要求)**:
- 每次产生业务记录(一次合作、一张寄样单、一次投流)时,把**当时生效的佣金档/策略数值快照写进这条记录**。
- 管理员改配置(比如 L2 从 6% 调成 6.5%)→ **只影响之后新产生的记录,历史记录里的快照值一律不动**。
- 达人当前等级变了同理:不回溯已产生的合作记录。
- 配置表带版本号 + 生效时间,可追溯"当时为什么是这个数"。
- 佣金档的**档位本身也是配置**(现在 5/6/7,以后加 8% 或小数档不用改代码)。

看板随之解决"5% 的达人有多少":按当前档位聚合 + 按历史快照聚合两种口径都能出。

## 5. 核心流程

### 5.1 达人智能录入(R1/R9/答复#9)
- 商务(或达人本人在 H5)粘贴一段微信自我介绍 → **正则 + LLM 解析**出抖音号/UID/主页链接/昵称/粉丝数/品类/联系方式,低置信度字段标黄人工确认。
- 撞库查重(UID/抖音号/手机号)→ 老达人自动挂"第 N 次合作",展示历史产出。
- **历史数据迁移就用同一入口**:商务把微信里的存量达人逐个粘贴,零额外开发。
- 录入后一张卡片完成决策:跳主页看一眼 → 定级 → 佣金档(默认带出) → 投流机制(商家投/自投) → 是否寄样、寄哪几个品。

### 5.2 寄样与物流(R5/A1/答复#5)
- 审批(预设拒绝理由库,借鉴样例)→ 填单号/Excel 导入 → **聚合物流 API 自动跟踪**。
- 聚合平台选型(按你贴的调研):
  - **推荐:快递100 订阅式轨迹**(0.08~0.167 元/单,一个包裹全程只扣 1 次,状态变化主动推送回调,免轮询)+ 单号自动识别快递公司(39.9 元/万次)。新用户 100 次免费额度正好开发调试。
  - 快递鸟年付(488 元/年含 1 万单在途监控)适合单量稳定后切换核算——**代码里做 Provider 抽象,两家可切换**。❓ 先用快递100 起步,认不认?
- 状态自动流转:已发货 → 在途 → 派件 → **已签收**(时间戳落库)。
- **签收后催拍**:签收满 N 天(默认 7 天,管理员可配)无视频记录 → 自动给归属商务生成待办提醒(竞品里"签收超10天未传素材自动派跟进任务"是标准做法,我们做成可配置)。

### 5.3 产品中心(R6/A2,管理员管理、达人查看)
每个产品一个页面,五类内容:
1. **基本信息**:名称、价格、店铺、商品链接、默认佣金、上下架状态
2. **视频**:AI 生成视频/前三秒、爆款参考(商务丢抖音链接 → 自动转存+解析文案入池)、优秀达人成片
3. **图片素材**:白底图、详情图、场景图
4. **文档**:质检报告 PDF(展示对应"挂视频下方的报告 ID")、其他资质
5. **文案**:卖点、营销信息、拍摄要求
- 达人 H5 端:只看到**被开放**的产品(按等级默认 + 单独授权),可在线看、可下载(下载留痕);管理员可对单个素材关下载权限。
- 商务发达人时不再传文件,**发产品页链接即可**。

### 5.4 视频与投流协作(R4/R10/答复#6)
- 视频记录:达人视频链接登记(商务代录或达人 H5 提交)→ **自动转存视频文件**(防链接失效,留投流证据)→ 审核状态。
- 投流状态机(借鉴样例,已验证可用):待发起授权 → 待达人确认(可提醒) → 已授权 → 已投流 / 投流失败(留证截图) → 完成;每条打"商家投流/达人自投"标记。
- **千川开放接口 P0 就攻**(答复#6):你提供巨量引擎账号资质信息(账号主体类型、是否有服务商/代理商资质、千川账户角色),我先做接口资质与权限验证 spike;通了就做"一键发起绑定",不通降级为"一键复制绑定信息 + 人工状态机",不阻塞其他功能。
- 卡审知识库(R7):卡审记录归档(截图+文案+标签+日期)、近7/15/30天筛选、加星,达人端"拍摄前必读"。

## 6. 管理员总览看板(A3)

一页看全,支持时间范围切换(近7天/30天/自定义):

| 视图 | 指标 |
|---|---|
| 按商务 | 维护达人数、**新增达人数**、寄样数、产出视频数、爆款数、投流数、**产出 GMV**;新增达人的产出单列(衡量开发质量) |
| 按产品 | 合作达人数、寄样数、视频数、投流数、产出 GMV |
| 按达人等级/佣金档 | 各档人数分布、各等级产出贡献 |
| 明细下钻 | 任一数字点进去到达人/记录列表 |

> GMV 口径 ❓:蝉妈妈接入前,先用"人工登记的出单数据"还是先不展示 GMV 列?

## 7. 技术方案(答复#8:独立项目,按最优选)

| 层 | 选型 | 理由 |
|---|---|---|
| 后端 | **Python FastAPI + SQLAlchemy** | 达人信息 LLM 解析、后续与你的智能体/视频解析平台联动大概率同栈;开发快 |
| 数据 | **PostgreSQL**(你提供) | 主库;配置快照、JSONB 存解析原文 |
| 缓存/队列 | **Redis**(你提供)+ RQ/ARQ 任务队列 | 物流回调处理、视频转存下载、短信发送 |
| 对象存储 | **阿里云 OSS**(你提供) | 素材/PDF/转存视频/截图,前端直传 |
| 管理端 | **Vue 3 + Vite + Element Plus** | 清晰简约的后台标配,和样例同框架、迁移交互经验容易 |
| 达人端 | 同项目 H5 路由(移动优先) | 免 App;手机号 + **阿里云短信**验证码,验证后种 token |
| 外部集成 | 快递100(Provider 抽象)、阿里云短信、LLM API(达人解析)、千川开放接口(spike)、蝉妈妈(预留) | 全部走适配器,可换 |
| 部署 | Docker Compose 单机起步 | "小平台"体量,不上微服务 |

## 8. 分期(P0 已按要求扩容)

**P0(第一期,可直接上生产用)**
1. 账号与组织:管理员/商务登录、达人分配与转移
2. 达人库:智能粘贴录入(LLM 解析)+ 查重/合作轮次 + 标签 + 人工定级
3. 等级权益动态配置(佣金档/寄样策略/催拍天数,快照语义)
4. 寄样管理:审批(拒绝理由库)+ 快递100 轨迹自动跟踪 + 签收催拍待办
5. 产品中心:五类素材管理 + 按达人开放权限
6. 达人 H5:短信验证进入、自助提交资料、查看/下载素材
7. 管理员总览看板(按商务/按产品/按档位 + 下钻)
8. 千川接口资质验证 spike(结果决定 P1 形态)

**P1**
- 视频记录与审核(转存 + feed 式审核 + 时间点评论)、投流状态机、卡审知识库、蝉妈妈接入(费用评估通过后)、千川一键绑定落地

**P2**
- 自动定级建议(基于积累数据)、多店铺/多主体授权管理、财务对账(佣金结算单)、与视频平台深度联动

## 9. 竞品参考(为什么自建 + 抄什么)

| 竞品 | 是什么 | 我们借鉴 | 为什么不直接用 |
|---|---|---|---|
| [蝉圈圈](https://www.kolkoc.com/)(蝉妈妈旗下达人营销 CRM) | 多平台找达人/建联/线索分配/样品管理/绩效统计,[样品管理成本降70%、寄样沟通成本降90% 的案例](https://www.iyunying.org/zha/hot/297100.html) | 线索分配给商务、签收提醒、绩效统计的产品形态 | 按年付费 SaaS、数据在别人家;没有我们的佣金档/卡审知识库/AI素材联动;流程泛化,不贴牙膏单品类打法 |
| [MCN 达人管理系统(大鱼CRM 等)](https://www.dayucrm.com/blog/22038.html) | 达人档案企业资源池、商单/寄样/对账全流程 | **"签收超10天未传素材自动派跟进任务"**(我们的催拍待办)、达人资产归公司不归个人微信 | 面向 MCN 接商单场景,方向相反(我们是商家找达人) |
| [巨量百应](https://zhuanlan.zhihu.com/p/371614728) | 抖音官方人货撮合/机构经营平台 | 佣金按 UID 设置的操作对象(我们做操作指引与记录) | 官方平台,无法承载我们的内部管理流 |
| 大狗文化商家工作台(docs/01) | 商家侧审核闭环 | 免登录短链、feed 审核、时间点评论、投流状态机、拒绝理由库 | 无达人分级佣金/素材中台/卡审知识库/组织总览 |

结论:市面工具都在"建联撮合"或"审批闭环"单点,**没有一个同时覆盖"分级定佣 + 素材自助 + 卡审沉淀 + 商务绩效总览"的自用小平台**,自建成立,且刻意保持小而简。
