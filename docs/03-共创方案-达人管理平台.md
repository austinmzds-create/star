# 共创方案:达人管理平台(Draft v0.1)

> 基于:会议需求梳理(docs/02)+ 样例平台 Review(docs/01)
> 状态:待共创讨论,文中 ❓ 为需要拍板的开放问题

## 1. 产品定位一句话

给**只做牙膏品类**的抖音商家一套「达人全生命周期管理」系统:**招募识别 → 质量评估定档 → 寄样物流 → 素材赋能 → 视频审核 → 投流协作**,替代微信 + Excel;达人侧免登录短链自助,商务侧全局看板。

对比样例平台(大狗文化):它做的是"审批闭环",我们做的是"**达人资产运营**"——达人档案、分级佣金、素材中台、卡审知识库是我们的差异化。

## 2. 角色与入口

| 角色 | 入口 | 权限 |
|---|---|---|
| 商务/运营(内部) | 登录后台 | 达人库、审核、寄样、投流、素材维护、知识库维护 |
| 达人(外部) | 免登录短链(发朋友圈/私聊) | 自助提交资料、查看被开放的产品素材、拍摄必读、(可选)提交视频链接 |
| 管理员 | 登录后台 | 佣金档配置、评估规则配置、多店铺管理、账号管理 |

> 借鉴样例:达人短链免登录、零摩擦;吸取其教训:达人短链只暴露达人自己的最小视图,内部数据(手机号/地址/全量达人列表)绝不出现在免登录页面。

## 3. 核心:达人质量评估模型(Influencer Quality Assessment)

这是整个系统的中枢——评估结果同时驱动 **佣金档、寄样策略、审核通道、维护优先级** 四件事。

### 3.1 评分卡(v0,规则可配置)

| 维度 | 指标 | 数据来源 | 权重❓ |
|---|---|---|---|
| 账号基础 | 粉丝数、赞粉比 | 录入时解析 + 定期回刷 | 20% |
| 带货能力 | 近30天 GMV、橱窗/带货口碑分 | 人工录入 or 三方数据(蝉妈妈/百应导出)❓ | 30% |
| 内容匹配 | 母婴/儿童内容占比、目标人群契合 | 商务主页审核时人工打分(1-5) | 20% |
| 拍摄能力 | 能否口播、画质、脚本执行力 | 商务人工打分(1-5);桌拍-only 单独标记 | 15% |
| 履约历史 | 交付及时率、卡审率、爆款率、复购合作次数 | 系统自动累计(第2次合作起生效) | 15% |

### 3.2 等级 → 权益映射(默认值,管理员可改)

| 等级 | 定义 | 佣金档 | 寄样策略 | 审核通道 |
|---|---|---|---|---|
| L1 普通 | 新达人/基础达标 | 5% | 单品试合作 | 视频必审 |
| L2 优质 | 带货数据好或已有成功合作 | 6% | 可 2 品 | 视频必审,优先审 |
| L3 头部/爆款 | 出过爆款、稳定产出 | 7% | 全品类开放、主动派品 | 可免审/自动通过(样例的"优质达人"通道) |

- 系统给**建议等级**,商务可人工覆盖(留痕:谁改的、为什么)——评估是辅助决策,不取代商务判断。
- 每个达人档案页直接显示:当前等级、佣金档、各维度得分、历史合作记录。
- 看板:各佣金档人数分布、各等级 GMV 贡献、升降级流水——解决"5% 的有多少人我感知不到"。

❓ **共创点 1**:权重与阈值先拍脑袋定还是先跑两周人工打分数据再定?建议:先上"人工打分 + 自动累计履约",跑出数据后再调权重,不要一开始就过度自动化。
❓ **共创点 2**:近30天 GMV 从哪来?人工填(快)vs 蝉妈妈类三方(贵)vs 百应导出半自动(折中)。

## 5. 关键流程设计

### 5.1 达人智能录入(R1/R8)
1. 商务粘贴微信里达人发来的自我介绍(或达人在短链页自己粘贴)。
2. 解析器抽取:抖音号、UID、主页链接、昵称、粉丝数、品类标签、报价/佣金诉求。
   - 实现:正则抽链接/数字 + LLM 抽非结构化字段(昵称、品类、诉求),置信度低的字段标黄让人确认。
3. 查重:按 UID/抖音号/手机号撞库 → 命中则挂到已有档案,标"第 N 次合作"。
4. 生成待审核卡片:主页链接一键跳转,商务看完主页直接在卡片上打分(内容匹配、拍摄能力)→ 出建议等级 → 定佣金档 → 决定寄样。

### 5.2 寄样物流(R5)
- 审批通过 → 填/导入运单号(兼容样例的"文本粘贴/Excel 回填"方式)→ 对接聚合物流 API(快递100/快递鸟,按查询计费,约 0.03-0.1 元/单)。
- 状态自动流转:已发货 → 在途 → **已签收(触发:提醒商务/达人进入拍摄排期)** → 超时未签收预警。
- ❓ **共创点 3**:签收后 X 天未出视频要不要自动提醒商务跟进?X=?

### 5.3 素材中台(R6)
- 每个 SKU 一个素材页:白底图、卖点文案、质检报告 PDF(可下载,并展示"挂视频下方的报告 ID")、我们 AI 生成的视频/前三秒、**爆款参考池**。
- 爆款池录入:商务丢一条抖音链接 → 后台自动转存视频 + 解析文案(复用现有视频解析能力)→ 入池展示。
- 达人短链视图:只看到被开放的 SKU 的素材;下载留痕。

### 5.4 卡审知识库(R7)
- 每次卡审:一键归档(截图 Ctrl+V + 违规文案 + 违规类型标签 + 日期)。
- 达人端"拍摄前必读":按近 7/15/30 天分组 + 加星置顶(卡审规则随平台策略漂移,时效维度是刚需)。
- 商务端:发达人前系统提示"该品最近 7 天新增 N 条卡审记录"。

### 5.5 投流协作(R4/R10/R11)
- 状态机直接借鉴样例(已被验证):待发起授权 → 待达人确认(可提醒)→ 已授权 → 已投流/投流失败(留证截图)→ 完成;每条挂"商家投流/达人自投"标记。
- 多店铺:达人 × 店铺 维度记录授权关系(同一达人换店铺的品要重新授权)。
- ❓ **共创点 4**:千川开放平台接口(巨量引擎 open api)一般需要服务商/开发者资质,个体商家能否申请到"合作达人绑定"相关接口**待验证**——建议 P0 先做人工状态机 + 一键复制绑定所需信息(抖音号/合作码/天数),P2 再攻 API。

## 7. MVP 分期建议

| 阶段 | 内容 | 说明 |
|---|---|---|
| **P0(先跑起来)** | 达人库 + 智能粘贴录入 + 查重/合作轮次 + 人工评估打分 → 等级/佣金档 + 寄样审批 + 物流轨迹 API + 基础看板(佣金档分布) | 直接解决微信+Excel 最痛的三件事:录入、定档、查快递 |
| **P1** | 素材中台(含爆款池自动解析)+ 卡审知识库 + 达人免登录短链(自助申请 + 素材/必读查看) | 把商务的"重复发资料/重复教学"时间省下来 |
| **P2** | 视频审核 feed(时间点评论)+ 投流状态机 + 多店铺 + 千川 API 调研落地 + 评估模型自动化(履约数据驱动权重) | 借鉴样例已验证的交互 |

## 8. 开放问题汇总(等你拍板)

1. **评估权重冷启动**:先人工打分跑数据,还是直接上自动评分?(§3 共创点1)
2. **GMV 数据源**:人工/三方/半自动?(§3 共创点2)
3. **签收后催拍策略**:自动提醒的时机和文案(§5.2 共创点3)
4. **千川 API 资质**:需要客户提供巨量引擎账号角色信息才能验证(§5.5 共创点4)
5. **达人短链是否需要手机号验证码**:防链接扩散 vs 保持零摩擦
6. **技术栈**:样例是 Vue3 SPA + 免登录 token。我们内部端建议正经登录态;达人端短链。前后端选型跟你现有智能体/视频解析服务的栈对齐,待定
7. **数据迁移**:现有微信里的历史达人,是商务陆续粘贴录入,还是先集中导一批 Excel?
