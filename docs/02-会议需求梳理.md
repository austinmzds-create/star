# 会议需求梳理(2026-07 郑创展团队 × 牟振东)

> 客户:牙膏品类电商(优伢宝贝),抖音渠道,达人分销 + 千川投流模式
> 现状:全流程在微信 + Excel 里人肉维护;参考过同行(大狗文化)的商家工作台链接

## 1. 业务现状流程(As-Is)

```
达人从朋友圈/私域看到产品 → 微信私聊自我介绍(附抖音号/主页链接/粉丝数)
→ 商务人工点开主页审核质量(粉丝、点赞、带货情况、内容品类是否母婴匹配)
→ 决定是否寄样(好达人可一次寄2-3个品)+ 定佣金档(5%/6%/7%)
→ 人工寄样、Excel 记单号、人工查快递
→ 达人收样后自行排期拍摄(时间不可控,约一周)
→ 达人发视频、发链接给商务 → 商务审核 → 卡审则指导修改
→ 千川后台人工绑定达人(抖音号→合作码→自定义天数→达人同意)
→ 百应后台按 UID 设佣金(无需达人同意)
→ 商家投流(绝大多数),少数达人自投
→ 爆款素材由商务转发给其他达人参考;质检报告 ZIP(PDF)逐个发
```

## 2. 需求清单(按会议共识)

### P0 已明确要做
| # | 需求 | 会议出处/细节 |
|---|---|---|
| R1 | **达人智能录入**:粘贴达人自我介绍文本 → 自动识别抖音号/UID/主页链接/粉丝数等填表;商务或达人本人都可操作 | "就像发快递一样,把一坨信息放到文本里,自动全部识别出来" |
| R2 | **达人档案管理**:线上化取代微信+Excel;标记第几次合作、历史产出、带过哪些品 | "他二次申请进来,我们可以加标识,他之前历史产出多少都可以检索到" |
| R3 | **佣金档位管理**:预设 5%/6%/7%,页面一键选择;可统计各档位人数 | "我现在佣金为 5 的用户有多少?我其实感知不到" |
| R4 | **投流机制标记**:商家投流(默认)/ 达人自投,页面按钮直接绑定 | 涉及金额区分;达人自投极少 |
| R5 | **寄样物流线上化**:发货单号录到达人名下,接第三方物流 API 实时查询到货状态(约几分钱/单) | "不要再做 Excel,全部线上化" |
| R6 | **产品素材中台**:按品(SKU)组织,白底图/营销信息/卖点/质检报告 PDF(允许下载,报告 ID 挂视频下方)/自产 AI 视频(智能体生成前三秒)/爆款视频池 | "商务找到爆款视频链接直接丢上来,自动下载+解析,所有达人点进产品就能看" |
| R7 | **卡审知识库**:牙膏品类卡审规范;每次卡审的截图/文案记录归档;近几天/一周/半月/一月筛选;加星;达人端"拍摄前必读" | "未成年可出镜但不能口播"这类经验要沉淀 |
| R8 | **达人自助入口**:朋友圈发平台域名,达人自己进来粘贴信息一键发起申请 | "后续发朋友圈直接把域名放上去" |
| R9 | **按达人开放产品权限**:好达人开放多品;一般达人先开一个品 | "根据达人质量,好的可以2-3个品一起发" |

### P1 探索项
| # | 需求 | 备注 |
|---|---|---|
| R10 | **千川一键绑定**:调研巨量千川开放接口,平台内一键发起绑定(仍需达人同意) | "我到时候可以给你加个按钮,直接一键绑定"——接口可行性待验证 |
| R11 | **多店铺/多主体**:不同品挂不同店铺,达人需按店铺二次授权,平台要能管理多商户账户 | 会议 32:09 段确认 |
| R12 | **视频链接自助提交**:达人拍完在平台提交链接,商务收到即投流 | 结论:先不做强制,保留人与人沟通;平台可作为可选通道 |

### 明确不做 / 边界
- ❌ 微信批量群发、自动聊天(需求极少,且有风控风险)
- ❌ 拉达人群(达人交叉会互相看到、有竞争甚至举报风险,商务不希望达人有交叉)
- ❌ 替代商务与达人的人工沟通(卡审指导、催拍等保留人对人)
- ❌ 达人自愿填长表单(达人是主动方、我们是被动方,不能给达人增加填表负担——所以才要"粘贴即识别")

## 3. 达人质量评估口径(会议原话提炼)

哲彪(商务)口述的人工评估流程,即评估模型的种子规则:
1. 看**粉丝数**与**点赞量**(账号基础盘)
2. 看**整个账号的带货情况**(近30天 GMV、橱窗)
3. 看**内容品类匹配度**——偏母婴/儿童内容,与儿童牙膏人群相符,"搜索一下它的品类,比较高"
4. 看**主页视频拍摄质量**(是否只支持桌拍、能否口播)
5. 结论驱动三件事:**佣金档(5/6/7%)、寄样数量(1品 vs 多品)、是否重点维护**

## 4. 关键约束
- 达人排期不可控(样品到手后拍摄时间由达人自己排)
- 卡审是最大沟通成本点,规范会随平台策略**按周变化**(一个月前和这个月的卡审点可能不同)
- 佣金设置在百应后台按 UID 操作,无需达人同意;千川绑定必须达人同意
- 客户长期只做牙膏品类 → 卡审知识库可以做深做专
