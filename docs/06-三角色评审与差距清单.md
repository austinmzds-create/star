# 06 · 三角色评审与差距清单（v0.4 阶段性）

> 评审维度：操作流程 / 操作便捷度 / 查看便捷度 / 各模块增删查改（CRUD）完善度 / 需求符合度。
> 角色：达人（H5）· 商务（BD）· 管理员（Admin）。基于全量前端视图 + 后端接口 + 需求文档交叉核对。

---

## 一、总体结论

| 角色 | 成熟度 | 一句话判断 |
|---|---|---|
| **达人（H5）** | ★★★★☆ | 体验完整、数据隔离到位，是当前最成熟的一端；缺"看自己视频/投流进度"与结构化改资料。 |
| **商务（BD）** | ★★★☆☆ | 主链路已通、录入/复制/建单便捷；但**跨商务越权**、部分**增改缺失**、列表**无分页无搜索**。 |
| **管理员** | ★★★☆☆ | 功能齐，但**与商务几乎完全等同**——"仅管理员"的管理项没有锁死（这与你先前"商务=管理员"的口径有关，但部分项需重新拍板）。 |

核心三件事：① 状态操作接口存在**跨商务越权**（bug，与列表已隔离的意图矛盾）；② 一批模块**增/改/删不完整**；③ **管理员 vs 商务边界**需要你拍板并落地。

---

## 二、按角色走查

### 2.1 达人（H5）

- **操作流程**：验证码进入 → 资料卡（自助粘贴更新）→ 下拉选产品看资料/素材/物流 → 拍摄前必读。**流畅、闭环**。
- **操作便捷**：下拉选品、逐字段复制、文案一键复制、物流自助刷新——好。
- **查看便捷**：等级/佣金/合作码/收件信息、产品价格+佣金+卖点、素材分组（视频/文案/图片/报告）、寄样物流轨迹——齐。
- **CRUD**：R 齐；U 仅"整段粘贴重解析"；无 C/D（符合"达人不填长表单/不自建业务"的边界）。
- **缺口**：
  1. 资料只能**整段粘贴覆盖**，无结构化改单字段——易误改、体验糙。
  2. 看不到**自己的视频审核结果 / 投流进度**（需求 G2 要求"我的合作"，目前只有寄样）。

### 2.2 商务（BD）

- **操作流程**：工作台待办 → 达人库录入/定级 → 寄样审批/发货 → 视频审核 → 投流 → 卡审归档。**主链路通**。
- **操作便捷**：粘贴智能录入、撞库识别老达人、快捷建单、逐字段复制千川——好。
- **查看便捷**：达人一站式详情（档案+寄样+视频+投流+轮次+留痕）优秀；达人库有分页。**但**：
  - 列表筛选不全：达人库无"按商务/标签/佣金"筛选；
  - **寄样 / 视频 / 投流 / 产品 / 卡审列表无分页、无搜索**（数据一多就翻不动）。
- **CRUD 缺口**（详见第三节矩阵）：达人不可删、核心字段不可改；产品不可删、素材不可改；寄样单不可改；卡审记录不可改；出单登记只增、不可查改删。
- **权限问题（重点）**：
  - **跨商务越权（bug）**：`audit / ship / track / 发起投流 / 投流流转` 等状态接口**未校验达人归属**，A 商务知道 ID 就能操作 B 商务的单——而列表/建单/删除是**已按归属隔离**的，属明显不一致。
  - **越权到管理**：商务能进配置中心、加商务账号、改全局佣金/系统配置、看全员看板。这是先前"商务=管理员"的口径，但**"加账号/改全局配置/看全员"是否该锁死给管理员**需你拍板。

### 2.3 管理员

- **功能**：与商务相同 + 配置中心（等级权益/催拍天数/拒绝理由/商务管理）+ 总览看板。
- **问题**：路由、前端、后端**都没把"仅管理员"的能力锁死**。目前管理员与商务的差别仅在前端隐藏了两个按钮（"立即扫描""看板快捷入口"），而**对应后端接口商务仍可直达**。等于三角色实际是"两档"（内部/达人），管理员这一档形同虚设。

## 六、建议处理顺序

1. **先焊安全**（P0-1、P0-2、P0-4）——这些是 bug/红线，且改动集中、风险低。
2. **定角色边界**（P0-3）——需你一句话拍板，随后一次性收口。
3. **补关键 CRUD**（P1-5~8）——直接决定"能不能当真实业务用"。
4. **再上体验项**（P2）——feed 审核、自动转存等按你优先级排。
